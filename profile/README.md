## 📌 About This Organization

This GitHub organization contains the repositories created throughout the **CS2043 Operating Systems** module.

It is not limited to lecture notes. Separate repositories will be maintained for different areas of the module, including:

- Weekly learning notes
- Lecture and tutorial materials
- In-class activities
- Laboratory exercises
- Linux and command-line practice
- Process and thread implementations
- CPU scheduling simulations
- Synchronization exercises
- Deadlock-related problems
- Memory-management implementations
- File-system activities
- System programming exercises
- Assignments
- Individual and group projects
- Operating-system experiments
- Revision resources
- Exam preparation
- Additional research and learning

The main goal is to create a structured, version-controlled knowledge base that connects operating-system theory with practical system-level implementations.

## 🎯 Objectives

This organization is designed to:

- Organize all CS2043-related work in one place

- Connect operating-system theory with practical implementations
- Develop a strong understanding of how operating systems manage hardware and software resources
- Practise process, thread, memory, storage, and file-system concepts
- Understand concurrency, synchronization, and deadlock handling
- Gain experience with Linux and command-line tools
- Develop system-programming and debugging skills
- Maintain clear documentation for future revision
- Support laboratories, quizzes, assignments, presentations, and projects
- Build reusable academic and technical resources
- Develop good Git, GitHub, documentation, and software-engineering practices

## 📝 Weekly Notes Workflow

Weekly learning notes are initially created and organized in **Notion**.

The completed notes are then maintained in a dedicated GitHub repository for:

- Long-term storage
- Version control
- Easy accessibility
- Continuous improvement
- Revision
- Linking theoretical notes with code and laboratory work
- Preserving diagrams, examples, and external learning resources

Each weekly note may include:

1. Lecture concepts
2. Simplified explanations
3. Important definitions
4. Diagrams and visual explanations
5. Process-state diagrams
6. Scheduling timelines and Gantt charts
7. Step-by-step calculations
8. Algorithms and pseudocode
9. Linux commands and terminal examples
10. System-call examples
11. In-class activities
12. Laboratory work
13. Questions and answers
14. Common mistakes and misconceptions
15. Additional research
16. Weekly summaries
17. Active-recall questions
18. Revision checkpoints

The notes are intended to evolve continuously rather than remain as static copies of lecture slides.
